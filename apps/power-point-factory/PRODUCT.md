# Product

<!-- product-schema: 1 -->
## Platform

CLI + repo template (Bun, TypeScript). Output: .pptx, .pdf, .png.
## Users

Developers and AI agents (Claude Code) producing presentations for companies: board updates, QBRs, investor pitches, strategy proposals, project status, keynotes.
## Product Purpose

Turn a brief into a corporate-ready, on-brand, editable PowerPoint with no manual layout work, and prove its quality automatically before a human sees it.
## Positioning

Native editable PPTX (not images, not HTML) + measured text fit + render-based QA + a fresh-eyes review loop, all scriptable by an agent.
## Capabilities and Constraints

- Office-safe fonts only (decks must look identical on the presenter's laptop).
- Screenshots via LibreOffice approximate PowerPoint; Morph/animations are XML-validated, not visually verified.
- AI media requires a Kubeez API key; without it, labeled placeholders.
## Brand Commitments

No invented facts, numbers, quotes or real-company logos. Sample company (Halden Logistics) is fictional.
## Product Principles

1. Recipes are data; layouts are code; QA is mandatory.
2. One message per slide, answer first, end on decisions.
3. Every external tool behind one module.
4. Generated media is source: cached, committed, never billed twice.
