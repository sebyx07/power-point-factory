# Libraries — what we wrap and why

> As of 2026-11. Rule: every external tool sits behind one module in `src/` so it can be swapped.

| Job                      | Choice                                                        | Wrapped in                                | Why                                                                                  | Considered                                                                                                                                                                          |
| ------------------------ | ------------------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Write .pptx              | **pptxgenjs 4**                                               | `src/render/*`                            | native editable shapes, charts, tables, notes, media; pure JS; active                | python-pptx (Python, weaker charts), officegen (dead), docx-templates/pptx-automizer (template patching — add later for client .potx), Marp/Slidev/reveal (HTML, not editable PPTX) |
| Transitions + animations | **own OOXML injector**                                        | `src/render/motion*.ts`                   | no JS library writes `<p:timing>`; we post-process with jszip                        | Aspose.Slides (commercial), manual PowerPoint                                                                                                                                       |
| Text metrics             | **opentype.js** + metric-compatible fonts                     | `src/text/*`                              | exact advance widths → wrap/fit matches PowerPoint; raw advances + kerning (no GSUB) | harfbuzzjs (WASM, exact shaping — upgrade path if CJK/RTL decks appear), canvas measureText (needs native canvas)                                                                   |
| Images                   | **sharp** (libvips, C/C++)                                    | `src/assets/resolve.ts`, `qa/*`           | crop-to-box, attention-crop, mozjpeg, SVG→PNG, compositing, raw pixel access         | jimp (slow), ImageMagick (shell)                                                                                                                                                    |
| Icons                    | **lucide-static**                                             | `src/assets/icons.ts`                     | 1,600+ consistent stroke icons, ISC; tinted to theme                                 | Font Awesome (licensing tiers), Material Symbols                                                                                                                                    |
| Render for QA            | **LibreOffice headless** (C++) → **poppler `pdftoppm`** (C++) | `src/qa/render.ts`                        | only free engine that renders PPTX faithfully; isolated profile per deck             | Office via COM (Windows only), unoserver (daemon — use if render time matters)                                                                                                      |
| Visual regression        | **pixelmatch**                                                | `src/qa/baseline.ts`                      | tiny, exact, anti-aliasing aware                                                     | odiff (faster native — swap if decks get huge)                                                                                                                                      |
| PPTX validation          | **jszip** + **fast-xml-parser**                               | `src/qa/structure.ts`, `render/motion.ts` | open the zip, validate every XML part                                                | OOXML SDK validator (.NET)                                                                                                                                                          |
| AI media                 | **Kubeez REST**                                               | `src/assets/kubeez/*`                     | one API for image, video, music, cut-outs; async jobs; CDN-optimized outputs         | per-vendor SDKs (OpenAI, Google, Runway…)                                                                                                                                           |
| Lint/format              | **Biome**                                                     | `bin/check`                               | one fast tool                                                                        | ESLint + Prettier                                                                                                                                                                   |

## Upgrade paths, when needed

- **Client templates (.potx/.pptx masters):** add `pptx-automizer` behind `src/render/template.ts` to place our scenes into a client's master slides.
- **Exact shaping (Arabic, Hindi, CJK):** swap `textWidthPt` to harfbuzzjs; nothing else changes.
- **Faster renders:** keep a `unoserver` daemon and point `src/qa/render.ts` at it.
- **Video transcoding:** if ffmpeg is installed, re-encode H.264 + faststart before embedding (Kubeez `optimized_url` is used today).
